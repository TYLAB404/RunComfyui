🌐 云端部署与安全隔离规范

  • 零明文落盘 (Zero Plaintext at Rest)：所有 API Key 均采用 AES-256 加密存储在 data/config.json，即使服务器磁盘备份被拷贝也无法直接读取明文。
  • 环境变量隔离：若需最高安全级别，可在云服务器设置环境变量 RUNNINGHUB_MASTER_SECRET="你的高强随机串"，系统将自动使用该环境主密钥进行派生加解密。
  • Git 仓库自动防泄露：程序已配置 .gitignore，主加密密钥 data/.secret.key 绝不会被推送至公开或私有 Git 仓库。
  • 局域网与外网反代：部署在云服务器或 VPS 时，推荐使用 Nginx 配置 HTTPS 证书并设置 Basic Auth 或反向代理端口，实现端到端传输加密。
