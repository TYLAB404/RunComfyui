# RunningHub Web Controller (智算工作流调度中枢)

一套现代化、自适应、高安全性的 RunningHub (ComfyUI 云端工作流) 全流程 Web 调度与用户运营平台。

---

## 🌟 核心特性

- **🎨 ComfyUI 拓扑全自适应**：智能探测并提取任意云端工作流的节点参数（提示词、采样器、步数、CFG、Latent分辨率、参考图/视频上传），前端表单全自动渲染。
- **🛡️ 纯远端直链模式（零落盘 · 零中转）**：
  - 生成的视频与原图直接走腾讯云 COS 亚太/国内加速 CDN，不占用部署服务器任何磁盘空间与下载流量。
  - 即使部署在 10GB 极小硬盘的海外服务器上，也永远不会爆盘，彻底保护隐私与数据合规。
- **👤 现代化用户鉴权系统（参考 RunComfyui 风格）**：
  - 工业级 PBKDF2-HMAC-SHA256 密码哈希，内置 Salt，杜绝彩虹表与碰撞破解。
  - HS256 JWT 无状态令牌认证，首位注册用户自动提权为超级管理员。
  - 多租户数据隔离：普通用户仅能查看自己的生成记录，管理员统览全平台任务流水。
- **🤖 Cloudflare Turnstile 智能人机防护**：
  - 无感验证码集成，后台可自由开启/关闭，轻松填入 Site Key 与 Secret Key 即刻抵御自动化机器人与撞库攻击。
- **👑 开发者后台管理面板**：
  - 系统概览仪表盘（注册量、活跃数、生成量、累计消耗 RH 币实时统计）。
  - 用户档案与权限编辑（设置管理员、增减算力点数、封禁、重置密码）。
  - 全局任务审计流水与系统参数即时配置。
- **📱 移动端与全平台深度自适应**：
  - 手机端专属底部高灵敏悬浮导航栏，彻底消除标签错位与挤压。
  - 触控友好型滑块与预设按钮，手机浏览器秒开体验。
- **🔐 多密钥保险箱与静态落盘加密**：
  - 支持多 RunningHub API Key 密钥池管理与无缝切换。
  - 所有密钥经 Fernet (AES-128-CBC + HMAC-SHA256) 强加密持久化，防数据备份泄露。

## 🚀 快速启动

### 1. 环境准备
确保已安装 Python 3.9+。

```bash
# 克隆仓库
git clone <你的 GitHub 仓库地址>
cd RunComfyui

# 安装依赖
pip install -r requirements.txt
```

### 2. 启动服务
```bash
python app.py
```
服务将在 `http://0.0.0.0:8000` 启动。访问该地址即可进入控制台。

> **Windows 快捷启动**：直接双击运行目录下的 `start_web.bat`。

## 🛡️ Cloudflare Turnstile 配置指南

1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)，在左侧导航进入 **Turnstile**。
2. 点击 **Add site (添加站点)**：
   - 站点名称：输入自定义名称（例如 `RunningHub Web`）。
   - 域名：输入你的域名（开发阶段可添加 `localhost` 与 `127.0.0.1`）。
   - 小部件模式：推荐选择 **Managed (托管/智能无感验证)**。
3. 创建后获取 **Site Key (站点密钥)** 与 **Secret Key (通信私钥)**。
4. 注册并登录进入本系统的「后台管理」->「安全设置」：
   - 勾选 **强制启用 Cloudflare Turnstile 人机验证**。
   - 分别填入 **Site Key** 与 **Secret Key**。
   - 点击保存，登录注册弹窗将即刻启用人机安全拦截！

## 📦 云端部署建议

- **服务器推荐**：阿里云/腾讯云香港轻量应用服务器（2核4G，约 34~50 元/月），免备案且国内直连延迟仅 30~50ms。
- **进程守护**：
  使用 `systemd` 或 `supervisor` 在后台常驻运行，或通过 Docker 容器化部署。
- **反向代理**：
  使用 Nginx 或 Caddy 配置 HTTPS 域名访问。
